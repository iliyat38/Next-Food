# 🍔 Next Foodies — Community Recipe Sharing Platform

A modern food-sharing platform built with **Next.js App Router** that allows users to discover meals shared by the community and publish their own recipes with images and detailed cooking instructions.

This project was built to gain hands-on experience with modern **Next.js full-stack development**, focusing on Server Components, Server Actions, dynamic routing, form handling, image uploads, and data persistence.

---

## 🚀 Key Features

* 🍽️ **Community Recipes** — Browse meals shared by other users.

* 📖 **Detailed Recipe Pages** — View ingredients, cooking instructions, and meal images.

* ✍️ **Create & Share Recipes** — Submit your own meals through an interactive form.

* 📸 **Image Upload Support** — Upload food images together with recipe information.

* ⚡ **Server Actions** — Handle form submissions and mutations directly on the server.

* 🗄️ **Database Integration** — Persist recipes and user-generated content.

* 🧭 **Dynamic Routing** — Generate unique pages for every recipe using dynamic route segments.

* ⏳ **Loading States** — Improve user experience with route-level loading UI.

* ❌ **Error Handling** — Gracefully handle unexpected application errors.

* 🎨 **Responsive Design** — Optimized for desktop, tablet, and mobile devices.

* 🖼️ **Next.js Image Optimization** — Fast image loading and optimization using the `next/image` component.

* 🚀 **Server-First Rendering** — Leverage Next.js rendering strategies for improved performance.

## 🧠 Architectural Highlights

### 🏗️ Server-First Architecture

Built using Next.js App Router with a server-centric approach, minimizing unnecessary client-side JavaScript and improving overall performance.

### ⚡ Server Actions

Implemented Server Actions for handling meal submissions without creating traditional API endpoints.

### 📂 Dynamic Route Segments

Each recipe is rendered through dynamic routes, enabling scalable content management and shareable URLs.

### 📸 File Upload Handling

Integrated image upload functionality to allow users to share visual content alongside recipes.

### 🗄️ Persistent Data Storage

Recipes are stored and retrieved from a database, creating a realistic full-stack workflow.

### 🚀 Performance Optimization

Utilized built-in Next.js optimizations including:

* Server Components
* Image Optimization
* Route-Based Code Splitting
* Efficient Data Fetching
